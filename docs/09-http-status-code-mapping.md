# 智慧医疗多院区挂号与号源调度系统：HTTP 状态码对照表

## 1. 使用约定

本文档定义本期三个 API 的 HTTP 返回状态及触发条件。后端实现遵循 [backend-conventions.md](backend-conventions.md)：Controller 统一返回 `Result<VO>`，业务异常由全局异常处理器转换为统一错误体。所有非 `2xx` 响应均须返回：

```json
{
  "code": 500,
  "message": "面向调用方的错误说明",
  "data": null,
  "traceId": "请求链路追踪标识"
}
```

`code` 为整数，且与实际 HTTP 状态码完全一致；例如 `404 Not Found` 响应的 `code` 为 `404`。

## 2. 状态码总表

| HTTP 状态 | 名称 | 适用场景 | 调用方处理建议 |
| --- | --- | --- | --- |
| `200 OK` | 请求成功 | 查询成功；排班余量已写入数据库且对应医生缓存已成功失效 | 解析成功响应 |
| `400 Bad Request` | 请求参数错误 | 路径 ID 非正整数/格式非法；更新容量缺失、非整数或为负数 | 修正参数后重新请求；无需重试原请求 |
| `404 Not Found` | 资源不存在 | 挂号单、医生或排班不存在 | 提示资源不存在；无需重试原请求 |
| `500 Internal Server Error` | 服务端内部错误 | 挂号详情的关键关联数据缺失；数据库查询或更新失败；缓存失效/协调发生非依赖不可用类的最终错误 | 记录 `traceId`，稍后重试或联系技术支持 |
| `503 Service Unavailable` | 服务暂不可用 | Redis 不可用，或缓存删除、读写协调等依赖故障在有限重试后仍未恢复 | 可按客户端重试策略稍后重试；院办操作不得视为成功 |

`401 Unauthorized`、`403 Forbidden` 的认证与授权协议尚未在本期需求中定义，因此不纳入既定契约；认证接入时应为后台调整接口补充对应状态与错误码。

## 3. 接口—状态码矩阵

| 接口 | `200` | `400` | `404` | `500` | `503` |
| --- | --- | --- | --- | --- | --- |
| `GET /api/appointments/{appointmentId}` | 返回有限的挂号详情树；病历不存在时 `medicalRecord: null` | `appointmentId` 非法 | 挂号单不存在 | 患者、排班、医生、科室或院区等关键关联缺失；其他服务端异常 | 不适用 |
| `GET /api/doctors/{doctorId}/schedules` | 返回医生摘要及排序后的排班列表；无排班返回 `[]` | `doctorId` 非法 | 医生不存在 | 数据库读取、响应组装等服务端异常 | 当前读取链路未规定为对外失败；缓存写入失败时可返回本次数据库查询结果并记录监控 |
| `PATCH /api/admin/schedules/{scheduleId}/capacity` | 数据库更新成功，且 `hospital:doctor:schedules:{doctorId}` 已成功删除 | `scheduleId` 非法，或 `capacity` 缺失、非整数、负数 | 排班不存在 | 数据库更新失败；缓存失效或协调发生内部最终错误 | Redis 不可用，或缓存删除/协调的依赖故障最终失败 |

## 4. API-03 状态码判定顺序

排班调整接口按以下规则判定返回码，避免在缓存未失效时错误返回成功：

```text
参数不合法                         → 400
排班不存在                         → 404
数据库更新失败                     → 500
数据库提交成功，Redis 依赖不可用   → 503
数据库提交成功，缓存协调内部失败   → 500
数据库提交成功，缓存删除成功       → 200
```

无论最终返回 `500` 还是 `503`，缓存失效失败的排班调整都不得返回 `200`。服务端日志与告警应包含 `scheduleId`、`doctorId`、失败原因和 `traceId`，但不得记录身份证号或病历内容。

## 5. 典型响应示例

### 参数错误（400）

```json
{
  "code": 400,
  "message": "capacity 必须为非负整数",
  "data": null,
  "traceId": "6d486c3d7e8c4c5a"
}
```

### 资源不存在（404）

```json
{
  "code": 404,
  "message": "排班不存在",
  "data": null,
  "traceId": "6d486c3d7e8c4c5b"
}
```

### 缓存依赖不可用（503）

```json
{
  "code": 503,
  "message": "排班更新后的缓存失效未完成，请稍后重试",
  "data": null,
  "traceId": "6d486c3d7e8c4c5c"
}
```
